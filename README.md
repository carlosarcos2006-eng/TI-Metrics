# TI-Metrics

Engine de Analítica de Logs y Monitoreo de Infraestructura.

## Descripción

TI-Metrics es una aplicación de consola desarrollada en Python 3
para procesar registros de infraestructura TI, analizar eventos,
consumir información geográfica mediante una API REST y generar
métricas y reportes.

## Tecnologías

- Python 3
- Requests
- Pytest
- Git
- GitHub

## Estructura

- `data/`: archivos de entrada y reportes.
- `src/`: código fuente.
- `tests/`: pruebas automatizadas.
- `docs/`: documentación técnica y UML.
- `PROMPTS.md`: auditoría de uso de inteligencia artificial.
